Hackathon track: gets measurably better with every run

A portfolio agent for every client that gets measurably better with every run.

Each client gets their own agent. It rebalances their portfolio to their risk profile and life events, like a layoff or a new child, and only recommends. A person approves every trade.

Muse rewrites the agent's playbook from its failures. An upgrade ships only if it beats its parent on clients it has never seen, keeps every regression case passing, and clears an independent Gemini compliance review.
