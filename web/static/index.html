Every client gets their own agent.

ballast. gives advisory firms a portfolio agent for each client. It rebalances to the client's risk profile and to what is happening in their life: a layoff, a new child, a marriage, an inheritance.

Who it's for
Registered investment advisers and the households they serve, especially when life changes fast.
What you get
A recommendation for every client with a cited reason for every trade. An advisor approves it. ballast. never trades on its own.
Why trust it
It ships an upgrade only if it beats the last version on clients it has never seen. When conditions shift, it catches its own drift and rolls back.

Hackathon track: gets measurably better with every runPowered by Muse, Meta Model API

The genome

Each agent runs on a playbook: a prompt, a set of skills and a turn budget. Muse rewrites it from real failures. Every change is a mutation, and only mutations that prove themselves on unseen clients survive.
